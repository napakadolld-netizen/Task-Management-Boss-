เชื่อม Dayflow กับ Google Calendar

สถานะ: เตรียมระบบแล้ว ต้องตั้งค่า Google Cloud และฐานข้อมูลก่อนเชื่อมจริง ปฏิทิน Dayflow จะถูกสร้างแยกจากปฏิทินหลักเมื่อซิงก์ครั้งแรก

1. สร้าง Google Cloud Project

  1. เปิด Google Cloud Console แล้วสร้างโปรเจกต์ชื่อ Dayflow Calendar
  2. APIs & Services → Library → เปิด Google Calendar API
  3. Google Auth Platform → Branding: ตั้งชื่อแอป Dayflow และอีเมลติดต่อ
  4. Audience: สำหรับทดสอบส่วนตัวเลือก External / Testing และเพิ่มอีเมล Google ของคุณเป็น Test user
  5. Data Access: เพิ่ม openid, email และ https://www.googleapis.com/auth/calendar.app.created
  6. Clients → Create client → Web application
  7. Authorized redirect URI: https://task-management-boss.vercel.app/api/google-calendar/callback

2. ตั้งค่า Vercel

Settings → Environment Variables: เพิ่ม GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, GOOGLE_REDIRECT_URI และ DAYFLOW_TOKEN_ENCRYPTION_KEY รวมทั้งตรวจค่า Supabase เดิมตามคู่มือฉบับเต็ม

เก็บ Client Secret และกุญแจเข้ารหัสไว้ใน Vercel เท่านั้น ไม่ต้องส่งในแชต

3. ตั้งค่าฐานข้อมูลและทดสอบ

  1. รัน supabase-google-calendar-migration.sql ใน Supabase SQL Editor
  2. เปิด HTTPS Preview ที่ตั้งค่าบัญชีทดสอบไว้ เข้าสู่ Dayflow แล้วกด Google Calendar → เชื่อมบัญชี
  3. กด “ซิงก์ตอนนี้” เพื่อสร้างปฏิทิน Dayflow
  4. เพิ่มนัดหมายทดลองและติ๊กส่งไป Google จากนั้นทดสอบแก้ไขจากทั้งสองฝั่ง
  5. ทดสอบข้อมูลชนกันและการลบที่ต้องยืนยันก่อนอนุมัติ Production

การทำงานของรุ่นนี้

ซิงก์เมื่อเปิดเว็บและกดซิงก์เองได้ การทำงานเมื่อปิดเว็บต้องตั้ง scheduler เพิ่ม นัดหมายปกติ เต็มวันและหลายวันรองรับแล้ว ส่วนรายการเกิดซ้ำและประเภทพิเศษให้จัดการใน Google Calendar โดยระบบจะแจ้งเตือนและไม่แปลงรายการเหล่านั้นผิดรูปแบบ

คู่มือฉบับเต็มและรายละเอียดสำหรับผู้ตั้งค่า · กลับ Dayflow
