# Dayflow
เว็บจัดการงานส่วนตัวภาษาไทย รองรับ 13Enterprise, 13Education, DR.EV, EV Life Thailand และ Delivery Drone

## เริ่มใช้งาน
ต้องมี Python 3 (Node ใช้ตรวจ syntax เท่านั้น) ไม่ต้องติดตั้ง dependencies

```sh
cd /workspace/Task-Management-Boss-
npm start
```

เปิดเว็บผ่านพอร์ต 3000 ของเครื่องที่รัน หรือใช้ static hosting ที่รองรับ HTTPS

- เพิ่ม แก้ไข ลบ ค้นหา กรองโปรเจกต์ และเปลี่ยนสถานะงานได้
- งานที่ยังไม่เสร็จจะแสดงทุกวันตั้งแต่วันที่เริ่ม งานเสร็จแล้วจะแสดงในวันที่ทำเสร็จ
- วันที่ใช้เวลาท้องถิ่นของอุปกรณ์ เมื่อเปิดข้ามเที่ยงคืนระบบอัปเดตวันให้อัตโนมัติ
- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์และ origin เดิม ไม่ซิงก์ข้ามอุปกรณ์ ไม่ใช่ฐานข้อมูลบนเซิร์ฟเวอร์
- ส่งออก JSON เป็นระยะเพื่อสำรองข้อมูล การนำเข้ารวมตามรหัสงานและอัปเดตรหัสที่ซ้ำ
- สถานะเป็นสถานะล่าสุด ไม่ใช่ประวัติการเปลี่ยนสถานะย้อนหลัง
- ฟอนต์ Google เป็นทางเลือก หากออฟไลน์ใช้ฟอนต์ระบบได้

ตรวจ syntax: `npm run check`
